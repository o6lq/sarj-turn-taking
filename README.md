# نموذج «متى يسكت الوكيل»: فريقنا في تحدي سرج

نظام يسمع مكالمة عربية (لهجات سعودية وخليجية) كل **٢٠ ملي ثانية** ويقرر ثلاثة أشياء:

- **يكمّل**: العميل قال «إيه» أو كح، أو التلفزيون شغّال، أو صوت الوكيل نفسه رجع.
- **يسكت**: العميل يبي يتكلم («لا لا لحظة»، «كم المبلغ؟»). ولو طلع السكوت غلط، يرجع يكمّل خلال نص ثانية.
- **يرد**: بعد ما يخلّص العميل كلامه.

وفوقه **وكيل متكلم** للعرض: تكلمه بالمايك، يسكت لما تقاطعه، يسمعك، يرد بلهجة سعودية، ويرجع للنقطة اللي انقطعت.

## ١) التثبيت (مرة وحدة)

### على الماك (Apple Silicon)

```bash
gh auth login
gh repo clone o6lq/sarj-turn-taking && cd sarj-turn-taking
./setup.sh
```

### على ويندوز

في PowerShell:

```powershell
winget install -e --id Python.Python.3.12
winget install -e --id Git.Git
winget install -e --id GitHub.cli
```

سكّر PowerShell وافتحه من جديد:

```powershell
gh auth login
cd $HOME\Documents
gh repo clone o6lq/sarj-turn-taking
cd sarj-turn-taking
powershell -ExecutionPolicy Bypass -File setup_windows.ps1
```

التفاصيل والمشاكل الشائعة في **[WINDOWS.md](WINDOWS.md)**.

> السكربت يحمّل كل شي ويختمه بتشغيل الدرجة على مكالمات سرج. إذا طلع سطر يبدأ بـ`core`، كل شي شغّال.
> التحميل الأول: على الماك حوالي ٤ GB، وعلى ويندوز حوالي ٢ GB. عقل الوكيل المحلي Gemma 4 (١٥ GB) اختياري: `./setup.sh --local-brain`.

## ٢) جرّبه (صفحة العرض)

| ماك | ويندوز |
|---|---|
| `.venv/bin/python -m tools.live` | `.\.venv\Scripts\python -m tools.live` |

افتح **http://127.0.0.1:8790/demo** في **Chrome**. فيها خمس تبويبات:

| التبويب | وش فيه |
|---|---|
| **الفكرة** | الدرجات الحالية، والطبقات الثمان وكيف يفكر النظام |
| **جرّب حي** | كلّم الوكيل بالمايك وقاطعه. تشوف كل طبقة لحظة بلحظة، والدرجة الحية للمكالمة، وتقدر تصحّح قرار الوكيل |
| **مكالمات سرج** | اسمع أي مكالمة من الـ٢٤، وشوف قرارات النموذج على الخط الزمني |
| **النتائج** | الدرجات من ملفات القياس نفسها، ومقارنة العقول ونماذج الفهم |
| **كيف بنيناه** | البيانات، والتقطير من Claude، والأدوات |

**عقل الوكيل (Gemini API):** أنشئ مفتاح من [Google AI Studio](https://aistudio.google.com/apikey)، وسوّ ملف `.env` في مجلد المشروع فيه:

```
TT_BRAIN=gemini
GEMINI_API_KEY=مفتاحك
```

الملف ما ينرفع على GitHub. بعدها شغّل مرة وحدة `.venv/bin/python -m tools.prerender_voice` عشان تجهز جمل بداية المكالمة بصوت الوكيل (حوالي ٤ دقايق). إذا انقطع Gemini وقت المكالمة يكمّل الوكيل بصوت بديل. قرار السكوت نفسه يبقى محلي بالكامل على الجهاز.

**صوت ElevenLabs (اختياري):** أضف `ELEVENLABS_API_KEY=مفتاحك` في `.env` وأعد تشغيل الصفحة، ويظهر خيار ElevenLabs في قائمة الصوت. تقدر تحدد صوت معيّن بـ`ELEVENLABS_VOICE_ID`.

**عشان التجربة الحية تطلع صح:**

1. **سماعة رأس** (أو AirPods) تعطي أفضل نتيجة. مع سماعات اللابتوب خلّ الصوت متوسط.
2. افتح **تبويب واحد** فقط للعرض: بدء مكالمة جديدة ينهي المكالمة السابقة.
3. **سكّر البرامج الثقيلة** (LM Studio، ألعاب، تابات كثيرة). عقل الوكيل ياخذ ذاكرة كبيرة.
4. لما يسألك «معي الأستاذ؟» رد بجملة كاملة («إيه نعم، هلا»). منها يتعلّم صوتك.
5. جرّب: «إيه» (يكمّل)، «كم القيمة؟» (يسكت ويجاوب)، «لا لا لحظة، الأحد ما يناسبني» (يعرض بدائل)، «مو مهتم» (يودّعك).

## ٣) الأوامر اليومية

(على ويندوز اكتب `.\.venv\Scripts\python` بدل `.venv/bin/python`)

```bash
git pull                                              # آخر نسخة
.venv/bin/python -m tools.sim                         # درجة سرج على مكالماتهم الـ24 (دقيقة)
.venv/bin/python -m tools.sim --data data/dev-aug     # نفس المكالمات بظروف أصعب
.venv/bin/python -m tools.sim --data data/synth-test  # مكالمات ما شافها
.venv/bin/python -m tools.sim --calls GI-D01          # مكالمة وحدة
.venv/bin/python -m tools.loop --note "وش غيّرت"      # القياس الكامل + لوحة القياس
.venv/bin/python -m tools.loop --quick --note "وش غيّرت"  # قياس أسرع
.venv/bin/python -m tools.errors runs/sim-novel-test-latest  # وين الأخطاء بالضبط
.venv/bin/python -m tools.ablation                    # وش تضيف كل طبقة
.venv/bin/python -m ttbench.play --calls all          # الاختبار الرسمي بالوقت الحقيقي (10 دقايق)
python my_system.py --host 0.0.0.0                    # يوم فحص الاتصال والنهائي
```

## ٤) الأرقام الحالية

من ١٠٠، بنفس حسبة سرج الرسمية:

| | مكالمات سرج (٢٤) | الأصعب (٩٦) | أصوات جديدة (٦٠) | صياغات جديدة (١٢٠) | **الاختبار الأعمى (١٢٠)** |
|---|---|---|---|---|---|
| البدائي من سرج | 41.0 | 7.8 | 50.9 | — | — |
| **نموذجنا (ماك)** | **99.0** | **96.6** | **99.5** | **84.1** | **85.5** |

- رقم «مكالمات سرج» من الاختبار الرسمي بالوقت الحقيقي، والباقي من المحاكي بنفس حسبة سرج.
- «الأصعب» = نفس مكالمات سرج بضجيج مقهى، وخط هاتف ضيق، وسماعة خارجية.
- «الاختبار الأعمى» = جمل كتبها نموذج ثاني بدون ما يشوف نظامنا، وانقاس مرة وحدة بدون أي ضبط بعده. هذا أصدق رقم عندنا.
- كل الاختبارات بأصوات مولّدة، فالمتوقع على كلام بشري حقيقي ممكن يكون أقل.
- نموذج ويندوز (`policy-faster.json`) جاهز، بس لسا ما انجرّب على جهاز ويندوز.

## ٥) كيف يشتغل (باختصار)

| الطبقة | السؤال | الأداة |
|---|---|---|
| L0 | نظّف صوت العميل من صدى الوكيل | قناة الوكيل كمرجع |
| L1 | فيه صوت إنسان؟ | Silero VAD |
| L2 | هو العميل نفسه؟ قريب ولا بعيد؟ | بصمة CAM++، والعلو نسبةً لصوته |
| L3 | كيف قالها؟ (نبرة، انفعال) | YIN، نسبي للعميل |
| L4 | وش قال؟ | Cohere Transcribe Arabic (ماك) / faster-whisper (ويندوز) + قاموس خليجي |
| L4b | وش يقصد؟ | CAMeLBERT صغير تعلّم من Claude Opus (٧ ms) |
| L5 | القرار + RESUME | قواعد + نموذج متعلّم + المعنى |
| L6–7 | متى يرد؟ ووش يقول؟ | نهاية الدور + عقل الوكيل وصوته (Gemini API، للعرض فقط) |

التفاصيل: `docs/02-team-guide.html` (**ابدأ فيه**) و `docs/EXPERIMENTS.md` (كل تجربة: الفرضية، والنتيجة، والقرار).

**تسجيلات بأصواتنا الحقيقية:** الخطوات والموافقة وطريقة دمج تسجيلات الفريق في `docs/RECORDING.md`.

## ٦) الهيكل

| المجلد | وش فيه |
|---|---|
| `my_system.py` | نقطة الدخول اللي تشغّلها سرج |
| `turn/` | **نموذج القرار**: `policy.py` (القرار وكل الإعدادات) · `asr.py` (التفريغ) · `semantic.py` (المعنى) · `lexicon.py` (القاموس الخليجي) · `speaker.py` · `vad.py` · `echo.py` · `acoustic.py` |
| `convo/` | **الوكيل المتكلم**: `engine.py` (منطق المكالمة) · `brain.py` (العقل) · `voice.py` (الصوت) · `scenarios.py` (المكالمات وقواعد التصرّف) |
| `demo/` | صفحة العرض للمحكمين |
| `tools/` | المحاكي، والقياس، والتدريب، ومولّد المكالمات، والمعلّم والطالب، وصفحة التجربة |
| `models/` | Silero VAD + طبقة القرار المتعلّمة + نموذج المعنى (من الـrelease) |
| `data/dev` | مكالمات سرج الـ٢٤ · `data/live` تسجيلاتنا بالمايك |
| `ttbench/` | أداة سرج الرسمية. **لا تعدّلها** |

الملفات الكبيرة (النماذج وأصوات التوليد) في `~/Downloads/sarj-ext-data`، مو في git. تقدر تغيّر المكان بمتغيّر `TT_EXT_DIR`.

## ٧) قاعدة الفريق

1. أي تعديل نقيسه على **المجموعات الأربع** قبل ما نعتمده. **إذا رفع «سرج» ونزّل «الأصعب» أو «ما شافها»، ما نعتمده**، لأن معناه إننا حفظنا البيانات بدل ما نتحسن.
2. كل تجربة تنكتب في `docs/EXPERIMENTS.md`.
3. اشتغل على فرع، وارفع PR:
   ```bash
   git checkout -b اسمك/وصف-التعديل
   git add -A && git commit -m "وش سويت وليش"
   git push -u origin HEAD && gh pr create --fill
   ```

## تنبيه

- الريبو **خاص**. بيانات `data/dev` من حزمة سرج: لا تنشرونها.
- لا ترفعون تسجيلات صوت من الفحص أو النهائي (شرط سرج).
- لا تحطون أي مفتاح API في الريبو. المفاتيح في متغيرات البيئة على جهازك فقط.
