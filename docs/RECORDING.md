# تسجيلات الفريق بأصوات حقيقية

اختبار سرج المخفي فيه كلام بشري، وكل اختباراتنا إلى الحين بأصوات مولّدة. الهدف ٢٠–٣٠ تسجيل من الفريق كله، يعني ٥–٨ لكل شخص.

## قبل التسجيل

1. **الموافقة:** كل شخص يتسجل صوته يكتب في قروب الفريق: «أوافق على تسجيل صوتي لاختبار مشروع سرج». سجّل الفريق فقط، أو أحد من عائلتك وافق.
2. **ممنوع:** بيانات عملاء حقيقية، أرقام جوالات أو هويات حقيقية، وأي تسجيل من الفحص أو النهائي.
3. **الملفات تبقى عندك:** مجلد `data/live/audio` ما ينرفع على GitHub. شاركها عن طريق درايف الفريق بس.

## الإعداد (مرة وحدة)

أضف هذي السطور في ملف `.env` في مجلد المشروع:

```
TT_RECORDER=اسمك_بالإنجليزي
TT_DIALECT=najdi
TT_PLACE=quiet
```

- `TT_RECORDER`: حروف إنجليزية وأرقام فقط، مثل `asayel` أو `abdullah`. يخلّي أسماء ملفاتك مختلفة عن ملفات زملائك.
- `TT_DIALECT`: لهجتك، مثل `najdi` أو `hijazi` أو `sharqawi` أو `janoubi`.
- `TT_PLACE`: مكان التسجيل: `quiet` أو `cafe` أو `car` أو `street` أو `speakerphone`. غيّره كل ما غيّرت المكان، وأعد تشغيل الصفحة.

## التسجيل

1. شغّل الصفحة:
   ```bash
   .venv/bin/python -m tools.live
   ```
   على ويندوز: `.\.venv\Scripts\python -m tools.live`
2. افتح **http://127.0.0.1:8790/** (مو `/demo`)، واختر تبويب **«تحديات القرار»**.
3. اختر تحدي، واضغط **«ابدأ المحاولة»**.
4. قل أول شي «هلا، إيه معك» عشان النظام يتعرّف على صوتك، واسكت لين يبدأ الوكيل.
5. سوّ التحدي بشكل طبيعي، مثل ما تكلم موظف حقيقي، بدون ما تقرأ من ورقة.
6. اختر الجواب الصح: **«كان لازم يسكت»** أو **«كان لازم يكمّل»**. تنحفظ المحاولة باسم مثل `LV-asayel-001`.

## وش نسجّل

| النوع | المطلوب | تقريباً |
|---|---|---|
| مقاطعة حقيقية: اعتراض، سؤال، «لحظة»، تصحيح | يسكت | ٤٠٪ |
| تأييد وتردد: «إيه»، «أها»، «اممم خلني أشوف» | يكمّل | ٤٠٪ |
| تلفزيون، أو كلام لشخص ثاني بالغرفة | يكمّل | ٢٠٪ |

نوّع الأماكن: غرفة هادية، كوفي، سيارة، وسماعة الجوال الخارجية.

## القياس ودمج تسجيلات الفريق

1. كل شخص يضغط مجلدي `data/live/audio` و`data/live/labels` ويرفعهم في درايف الفريق.
2. على جهاز القياس، انسخ الملفات داخل نفس المجلدين، وبعدها:
   ```bash
   .venv/bin/python -m tools.live --manifest
   .venv/bin/python -m tools.sim --data data/live
   .venv/bin/python -m tools.errors runs/sim-live --data data/live
   ```
   الأمر الأخير يحتاج تشغيل المحاكي باسم: `.venv/bin/python -m tools.sim --data data/live --name live`.
3. القياس الرسمي بالوقت الحقيقي: `.venv/bin/python -m ttbench.play --data data/live --calls all`.

لا تعدّلون النظام عشان تسجيل معيّن. إذا لقيتوا خطأ يتكرر، اكتبوه في `docs/EXPERIMENTS.md` كنوع خطأ.
